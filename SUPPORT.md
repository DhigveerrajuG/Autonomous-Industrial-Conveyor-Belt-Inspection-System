# Getting Support

Thank you for using **Conveyor Sentinel AI: Autonomous Industrial Conveyor Belt Inspection System**!

Before creating a new issue, please review the resources below to find help quickly.

---

## 🔍 Search Existing Documentation & Issues

1. **[README.md](README.md)**: Check the prerequisites, installation instructions, quick-start guides, and API endpoint documentation.
2. **[GitHub Issues](https://github.com/DhigveerrajuG/Autonomous-Industrial-Conveyor-Belt-Inspection-System/issues)**: Search existing open and closed issues to see if your problem has already been addressed or solved.
3. **[GitHub Discussions](https://github.com/DhigveerrajuG/Autonomous-Industrial-Conveyor-Belt-Inspection-System/discussions)**: Join community discussions, ask general questions, and share project ideas.

---

## 🐛 Reporting Bugs

If you find a bug in the code, model inference, or dashboard:
1. Make sure you are using the latest version of the repository.
2. Open a bug report using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
3. Include your environment details (OS, Python version, camera source) and steps to reproduce.

---

## 💡 Proposing Features

Have an idea for a new defect class, sensor integration, or dashboard visualization?
- Submit a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md).
- Or propose a [Hardware / IoT Integration](.github/ISSUE_TEMPLATE/hardware_integration.md).

---

## 🔒 Security Inquiries

For security vulnerabilities, please refer to our **[Security Policy](SECURITY.md)** rather than filing a public issue.
