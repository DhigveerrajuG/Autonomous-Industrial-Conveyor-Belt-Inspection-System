# Security Policy

The Conveyor Sentinel AI project team takes the security and integrity of industrial monitoring software seriously. We appreciate responsible disclosure of potential security vulnerabilities.

---

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          | Status |
| ------- | ------------------ | ------ |
| 1.0.x   | :white_check_mark: | Active production & development line |
| < 1.0   | :x:                | Deprecated / unsupported |

---

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, **please do not open a public issue.** Publicly disclosing a vulnerability may put other users and installations at risk.

Instead, please report vulnerabilities privately using one of the following methods:

### Option 1: GitHub Private Vulnerability Reporting (Recommended)
1. Go to the repository's [Security Advisories tab](https://github.com/DhigveerrajuG/Autonomous-Industrial-Conveyor-Belt-Inspection-System/security/advisories).
2. Click **"Report a vulnerability"** to submit an advisory draft directly to the repository maintainers.

### Option 2: Email Disclosure
Send an email to the project maintainer at:
**[234122117+DhigveerrajuG@users.noreply.github.com](mailto:234122117+DhigveerrajuG@users.noreply.github.com)**

Please include:
- A description of the issue and potential impact.
- Clear steps to reproduce or a Proof of Concept (PoC).
- The operating system, Python version, and dependency versions used.
- Any suggested fixes or mitigations if available.

---

## Response Process

When a vulnerability report is received:

1. **Acknowledgment**: We will acknowledge receipt of your vulnerability report within **48 hours**.
2. **Assessment & Confirmation**: We will investigate and confirm the scope and severity of the vulnerability.
3. **Patch & Release**: A fix will be developed and tested in a private branch or advisory draft.
4. **Public Disclosure**: Once a patch is released, an advisory will be published acknowledging the reporter (if desired).

Thank you for helping keep Conveyor Sentinel and its users safe!
